Getting Started

Accessing the App

Open your browser and go to:

https://sandbox.phoenixhomeremodeling.net

Log in with the credentials in .env.local on the server (ADMIN_EMAIL and ADMIN_PASSWORD).

First Time Setup

  1. Log in and explore the 6 default agents
  2. Go to Settings → Company Knowledge Base and upload your service catalog, pricing, and FAQs
  3. Go to Settings → API Keys to generate a key for GHL or N8N
  4. Click any agent → Train tab → write a system prompt for that agent's role

Shows active agents, completed tasks, tokens used, and a live activity feed. The Hermes chat panel on the right controls everything with natural language.

Real-time Streaming

Results appear word-by-word as the AI writes them. The task thread auto-opens the moment you click Run — no waiting for completion to see progress.

Task Actions

Available in the top-right header of every task thread:

  • Cancel — red ✕ button while running or pending
  • Copy — copy result to clipboard
  • Export — download result as a .md file
  • Project — assign to a project via dropdown
  • Refine — chat input appears after completion to iterate on the result
  • Compact — appears after 4+ refine messages; summarises the conversation to free up context

Sub-agents

An agent can spawn a child agent mid-task using {{SPAWN:agent_id:task description}}. The child runs, completes, and the result feeds back to the parent automatically.

Training an Agent

System Prompt

The core instructions that shape every response. Go to Agent → Train → System Prompt. Every save creates a version you can roll back to via /api/agents/[id]/versions.

Knowledge Base (Files)

Upload PDFs, TXT, CSV, JSON, HTML, Markdown. Injected into every task the agent runs. Limit: 2MB per file.

Google Drive Folders

Link Drive folders directly to an agent in the Train tab. Files sync into the knowledge base on demand. Supports Google Docs, Sheets, Slides, PDFs, Word docs, and plain text. Requires Google OAuth connection in Settings.

Task Templates

Save reusable prompts with {{variable}} placeholders. Click Use → fill variables → dispatch. Templates live in the Train tab.

Company Knowledge Base

In Settings → Company Knowledge Base, upload files shared automatically by ALL agents. Perfect for service catalogs, pricing, and FAQs. Limit: 5MB per file.

Integrations

Configure per-agent in the Tools ⚡ tab. Agents call them using {{CALL:Name:{"key":"value"}}} — up to 3 calls per task. Use the ▶ Test button to verify each one.

Pipelines

Chain agents so the output of one step becomes the input of the next.

Step 1: Research Agent  → "Research top remodeling trends in Phoenix"
Step 2: Content Writer  → "Write a blog post based on the research above"
Step 3: Email Manager   → "Draft a newsletter from this blog post"
  • Use {{variable}} in step descriptions for dynamic inputs filled at run time
  • Toggle "Pass previous step output" to feed results forward
  • Trigger via ▶ Run button or API: POST /api/pipelines/[id]/run

Projects

Group related tasks to track a larger piece of work across multiple agents and sessions.

Creating a Project

Go to Projects in the sidebar → + New. Give it a name and optional description.

Adding Tasks to a Project

Open any task thread → click the Project button in the top-right header → select a project from the dropdown. The task appears immediately in that project's view.

Skills

External AI model endpoints your agents can call mid-task. Go to Skills in the sidebar to add them.

Agents call skills using: {{SKILL:skill_name:your prompt}}

Example Usage

"Write a blog post about kitchen remodeling. Use
{{SKILL:Groq Fast:Give me 5 catchy headlines for
a kitchen remodeling blog post in Phoenix}} to get
headlines first, then pick the best and write the full post."

The agent calls Groq, gets headlines, picks the best, and continues writing — all in one task.

Skills are OpenAI-compatible endpoints. Any model that supports the OpenAI chat completions API works here.

Event Triggers

Auto-run agents when something happens in GHL. Polls every 5 minutes. Configure in Triggers in the sidebar.

EventWhat fires
GHL New ContactCreates a task from your template and runs the selected agent
GHL New OpportunitySame, triggered by new opportunities

Template variables: {{name}}, {{email}}, {{phone}}, {{value}}, {{stage}}

First check covers the past hour. Subsequent checks only catch items created since the last check.

Outbound Webhooks

When a task completes, Claude OS POSTs the result to your configured URL — GHL, N8N, Slack, or your own endpoint. Configure in Settings → Outbound Webhooks.

{
  "event": "task.completed",
  "task_id": 42,
  "agent_id": "writer",
  "title": "Write follow-up email",
  "result": "Dear John...",
  "tokens_used": 850,
  "timestamp": "2026-06-03T14:22:11Z"
}

Available events: task.completed, task.failed, or both.

Semantic Search

AI-powered search across all past task results by meaning, not keywords. Press Ctrl+Shift+F anywhere in the app to open it.

Example: searching "kitchen leads Phoenix" finds tasks about kitchen remodeling leads even if those exact words aren't in the results. Results show a percentage match score.

Every completed task is automatically indexed. Powered by OpenAI's text-embedding-3-small model.

Email Health Report

A monthly email deliverability and engagement analysis powered by your GHL contact data. Go to 📧 Email Health in the sidebar.

Setup

Add your GHL credentials to .env.local on the server so the report runs without entering credentials each time:

GHL_API_KEY=pit-your-token-here
GHL_LOCATION_ID=your-location-id
GHL_DOMAIN=phxhomeremodeling.com

What it analyses

The report reads HitTheInbox tags already applied to your GHL contacts — 16 parallel queries, no full contact pull needed, completes in 2-3 seconds.

SectionWhat it showsSource
Health Score0-999 score based on list qualityCalculated from tag ratios

AI AnalysisAnalyst notes + prioritised action itemsGPT-5.4 based on tag data

Troubleshooting

Task stuck on Running

Run the clear command above. Tasks also auto-fail after 3 minutes via the global timeout.

Agent doesn't know about uploaded files

cd /root/agentic-os
node -e "const db=require('better-sqlite3')('data/claude-os.db');
console.log(db.prepare('SELECT agent_id,filename,length(content) as chars FROM agent_knowledge').all())"

If chars is under 100, the file wasn't extracted properly. Re-upload it. PDFs need npm install pdf-parse.

Build fails

git fetch origin && git reset --hard origin/master && npm install && npm run build && pm2 restart claude-os

Google Drive returns 0 files

Copy the folder ID from the URL — the part after /folders/. Shared Drives are supported. Make sure the folder is shared with your connected Google account.

OpenAI API test

cd /root/agentic-os
export $(grep -E "^OPENAI_API_KEY|^OPENAI_MODEL" .env.local | xargs)
node -e "
const OpenAI = require('openai').default;

  .catch(e => console.error('FAIL:', e.message));
"
